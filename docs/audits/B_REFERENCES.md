# B. Reference Audit — `References/` (27 boards)

**Auditor:** Agent B (Reference Auditor). **Date:** 2026-11-06. **Scope:** all 27 PNG boards in `References/`, each opened individually with the Read tool. Read-only audit; no repo files other than this report were changed.

**Rules applied**
- Written specs win on every number and mechanic (CLAUDE.md §3, owner directive). A board value that differs from a spec is recorded as a conflict and is not a requirement.
- Colours and micro-labels are visual estimates, not pixel-sampled. Unreadable text is marked **unreadable**.
- Spec section numbers are taken from the spec text where I read it. Sections marked *(index only)* were cited by `REFERENCE_INDEX.md` and not re-read.
- Family letters: A mechanical library, B trunk and workshop, C Music Box, D Carousel, E Windmill and Bakery, F Clock Tower and Theatre, G Tockton environment, H characters and automata, I gift and presentation, J future.
- Documents read for this audit: `PRODUCT_SPEC.md` §3.2, §6.1–6.4, §7, §3.5 (partial); `DATA_AND_BLUEPRINT_SPEC.md` §4.1, §5; `ART_ASSET_PIPELINE.md` §4–6, §11–12; `MECHANICAL_SOLVER_SPEC.md` (grep); `INTERACTION_SPEC.md` (lines 156–158, 198, 224); `GAMEPLAY_SYSTEMS.md` (grep); `SIMULATION_SPEC.md` and `DEPLOYMENT_RELEASE_PLAN.md` (speed targets, grep); `REFERENCE_INDEX.md` (read in full).
