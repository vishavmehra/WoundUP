## b) Discrepancies (image vs written docs; docs win)

Each item below was checked against the docs with Grep or Read before being recorded.

1. **Carousel part count.** Image 15 (Carousel Hero) shows a 9-part structure and says "Follow the 9-part structure". Image 16 shows 20 parts. PRODUCT_SPEC §6.2 says "Parts: 20". Use 20.
2. **Carousel platform speed.** Image 15 says "platform speed 0.4 rad/s (+/-10%)". Image 16 and PRODUCT_SPEC §6.2 say 0.5 rad/s. The 0.4 value in the docs belongs to the Music Box cylinder (PRODUCT_SPEC §6.1, MECHANICAL_SOLVER_SPEC). Use 0.5 for the carousel.
3. **Windmill part count.** Image 17 says "Total Parts 18 (internal breakdown)". Image 18, image 19, and PRODUCT_SPEC §6.3 say 24. Use 24.
4. **Clock Tower part count.** Image 20 says "Total parts 28" and its list has 8 rows. Image 21 and PRODUCT_SPEC §6.4 say 32. Use 32.
5. **Carousel gear reduction.** Image 07 (Guide) says "reduction 12:1". Image 07 (Infographic) says "Gear Train (6:1)". Neither is in the docs. Treat as unresolved; the solver's test values should come from the blueprint data, not the boards.
6. **Winding input.** Image 05 says key input is "~5-10 turns clockwise". INTERACTION_SPEC §10 defines one wind unit per 90 degrees, maximum 8 units, which is 720 degrees (2 full turns). Use the spec.
7. **X-ray activation.** Image 23 labels X-ray as "Toggle". INTERACTION_SPEC §11 says "Hold for approximately 0.4 seconds" and lists alternative activation as a later idea. Use hold.
8. **Frame rate.** Image 23 says "72-90 FPS target". PRODUCT_SPEC line 65-66, PROJECT_BIBLE, TECHNICAL_ARCHITECTURE.md line 830 say target 72, never below 60. Use 72/60.
9. **Gear module and tooth diameters (internal to images and to docs).**
   - Image 03 states "Module 0.002 m (2 mm)" but its 16-tooth gear is labelled 0.064 m diameter. A 2 mm module gives 32 mm (16 x 2). 0.064 m implies a 4 mm module.
   - Image 02 states "Gear module (default): 0.02 m" and "module 0.02 m (base)". That is a third value.
   - DATA_AND_BLUEPRINT_SPEC §4.1 IDs use `_m1` (`gear_spur_12_m1`, `gear_spur_24_m1`, `gear_spur_36_m1`). Those IDs imply module 1 and include a 36-tooth gear. Neither board lists 36 teeth. Image 03 and image 02 list 8, 12, 16, 20, 24, 32.
   - ART_ASSET_PIPELINE §11 says "10 tooth counts x 2 modules x 3 finishes". The boards show one module and 6 tooth counts.
   - Resolution: the docs define the module values; the implementer should pick a unit system and check it against DATA_AND_BLUEPRINT_SPEC §4.1 before reusing any board number.
10. **Music Box "12 parts" versus quantities.** PRODUCT_SPEC §6.1 says 12 parts. Image 12 lists 12 rows, but the quantities sum to 18 pieces (hinge x2, bracket x2, side panel x2, foot x4 add extra pieces). The docs do not say whether "parts" means rows or pieces. Ask the owner; do not invent.
11. **Music Box comb tine count.** Image 11 says "Comb tine count 15-24 (e.g. 18)". The tines visible on images 13 and 14 look like roughly 8-10, but this was not counted reliably. The docs do not state a tine count. Treat as unverified.
12. **Music Box dimensions.** Image 01 scale strip says music box "~0.18 m". Image 11 says 0.24 x 0.14 x 0.16 m. Use image 11 (a dedicated dimension board), and treat image 01 as approximate.
13. **Windmill speed label and tolerance.** Image 17 says "Target blade speed 0.6 rad/s (+/-10%)". Image 18 and the docs say millstone 0.6 rad/s (+/-15%). Image 19 says "windmill output shaft 0.6 rad/s" and "millstone 0.6 rad/s", although image 18 shows a 1:12 reduction between them. The docs use "millstone" with +/-15%. Use the docs.
14. **Character names.** Image 22 names Oswald, Elias, Luna, Pip and Clack. The docs define only Mira (letters 1-2) and Otto (letters 4-5). Mira's role "The Engineer" is not in the docs. These are unreconciled, not contradicted. Owner decision needed before using the names in-game. Update of 2026-11-06 (ADR-039): Otto is the baker, only Mira and Otto have figures, and the board names are not used ([TOCKTON_CHARACTERS.md](TOCKTON_CHARACTERS.md)).
15. **Trunk parts capacity.** Image 08 says "~40-60 standard parts (modular slots)". No such number was found in the docs. Unverified.
16. **Bakery part count.** Image 19 says "Bakery (16 parts)". No count was found in PRODUCT_SPEC or the other docs. Unverified.
17. **Gesture set.** Image 23 lists "two-hand rotate" and "snap" as gestures. INTERACTION_SPEC §6 (Pinch) and §7 (Part grabbing) define pinch and grab but do not define a separate snap gesture. Unverified, not contradicted.
18. **Triangle budgets.** Image 01 (10-20k / 5-10k / 2-5k tris) and image 03 (LOD0 3,200 / LOD1 1,200 / LOD2 400) give numbers. DECISIONS.md (around line 236) defers final polygon budgets to on-device profiling. Do not treat image numbers as targets.

## c) AI-artefact warnings (do NOT copy)

- **Garbled or invalid labels:** image 12 group label "Soup D" (should be "Group D"). Image 03 mixes the diagram "Circular pitch p = pi m (= 6.28 mm for m = 2)" with diameters in metres for the same gear.
- **Impossible or inconsistent geometry/numbers:**
  - Spur gear diameters vs module (see Discrepancy 9).
  - Music box tine count and quantities sum (Discrepancy 10-11).
  - Image 06 follower displacement graph shows one bell-shaped hump over 0-360 degrees, which is not a valid dwell-rise-fall profile. Do not use it as a cam profile.
  - Image 19 windmill and bakery share the same 0.6 rad/s value across a stated 1:12 reduction (Discrepancy 13).
- **Mismatched part counts inside the same series:** windmill 18 vs 24, clock tower 28 vs 32, carousel 9 vs 20 (Discrepancies 1, 3, 4).
- **Illegible micro-text:** small labels on images 01, 03, 16, 21 and 24 are not reliably legible at the sheet's resolution. Do not transcribe from them.
- **Decorative elements that are not game features:** lanterns, clock faces with incorrect numerals in some hero renders, extra flags, sign text on the workbench, and scenic backgrounds. Not part of the spec.
- **Possibly unscoped UI and NPC behaviour shown:** image 24 (Reference Guide-1, panels E and F; Sheet-2 has none of these) shows NPC dialogue bubbles, a "Quest indicator" and a "Music playing" overlay. The spec does not define NPC dialogue; check PRODUCT_SPEC and UI_UX_SPEC before implementing any of these.
- **Out-of-scope machines and areas:** image 21 says the theatre doors open every game hour. The theatre facade is in PRODUCT_SPEC §3.3 and §6.4 (theatre doors on the hour). The grand theatre performance is excluded (CLAUDE.md §14). Keep the facade only.
- **Anything with "sci-fi" or neon** appears in image 01 as a "Don't" example and must stay out.
