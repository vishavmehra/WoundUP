# Wound Up — Build Documentation Pack

This pack contains the initial Claude Code project instructions and engineering documentation.

## Start here

1. Copy `CLAUDE.md` to the root of the new `wound-up` repository.
2. Copy the `docs/` directory to the repository root.
3. Open Claude Code in the repository.
4. Ask Claude to read `CLAUDE.md` and all referenced documents before creating or changing code.
5. Have Claude perform the **documentation and environment audit only** first. Do not let it start feature implementation until the IWSDK starter and emulator proof are agreed.

## Important

The Wound Up Technical Design Doc remains the detailed source of truth. This pack translates its requirements and the supplied Devpost competition page into a Claude Code operating manual. Where the full Technical Design Doc specifies details not repeated here, Claude must consult that source document rather than inventing replacements.
